# 省级路网运行监测预警演示系统

## 一、项目简介

本项目是一套面向交通行业投标实践作业开发的 Web DEMO 系统。

系统参考《广东省级路网运行监测预警工程——省级交通综合视频汇聚及态势推演采购项目》的现场演示要求进行设计。

主要用于展示：

- 视频资源编目
- 智慧轮巡
- AI交通事件发现
- 低码流检测
- 高码流事件复核
- 堵点分析
- 多源数据研判
- 交通态势推演

本系统为教学及演示用途。

系统中的道路状态、交通流量、交通事件、视频数据和预测结果均为演示模拟数据，不代表真实交通运行情况。

## 第一阶段实现说明

- `src/assets/theme.css`：统一深蓝色视觉令牌、布局、响应式样式。
- `src/components/ChartPanel.vue`：按需使用 ECharts，监听容器尺寸并在卸载时销毁实例。
- `src/components/RoadNetwork.vue`：纯本地 SVG 路网示意，非真实地理位置。
- `src/data/`：摄像机、事件、路网与统计模拟数据；主线统一为 G4 K2035。
- `public/videos/`：可选本地 MP4 素材目录；无素材时使用本地 CSS 交通动画。
- 首页事件列表是固定演示数据；顶部时钟为电脑当前时间，图表统计截至模拟时间 14:00。
- 本期未训练 AI 或接入实时视频；五个核心页面的演示业务已实现，支持统一六步演示导航。

## 视频编目模块

当前模块包含 15 条模拟资源、三组可折叠目录、分页列表和四项全量统计。目录与查询条件共同生效；“重置”清空查询并返回广东省全部资源。关键词支持名称、编码、道路及桩号，填写后点击“查询”或按回车。

新增流程：点击“新增视频” → 选择领域、城市、道路、设备类型 → 填写桩号与名称 → 选择业务分类及两个独立目录 → “生成编码” → “保存”。定位字段变化后旧编码失效，必须重新生成；保存前再次检查唯一性。共享目录可分别留空、单独设置或同时设置。保存后清空筛选并显示全部资源首屏，便于找到新增项。

默认编码规则：

- 高速公路：`GD-GZ-G4-K2035-CAM-001`。
- 普通公路：`GD-GZ-RD-G105-K2035-CAM-001`，附加 `RD` 领域标识。
- 交通设施：`GD-GZ-FAC-G4-K2035-CAM-0001`，附加 `FAC` 标识并使用四位序号。
- 城市代码为 GZ / SZ / FS / DG / HZ，枪型与球型摄像机设备代码统一为 CAM。
- 同一基础编码按全量资源中的最大尾号递增，序号超出配置位数时自然扩展。
- “编码规则”面板可按领域调整标识和三位 / 四位序号；标识不可与其他领域重复。配置只影响新编码，历史资源保留创建时的规则快照。

支持修改视频名称、设备类型、业务分类及两个共享目录；编辑时锁定城市、道路、桩号、领域和编码。新增默认在线，在线 / 离线 / 故障均为模拟状态。“已共享资源”按至少归入一个目录的资源去重计数。页面统计与首页全省概览口径不同。

数据及规则保存在前端运行内存中，切换页面后保留，刷新浏览器后恢复初始数据。没有本地数据库、后端接口或真实共享服务。

主要文件：`src/views/VideoCatalog.vue`、`src/components/catalog/`、`src/data/cameras.js`、`src/data/catalogRules.js`、`src/assets/catalog.css`。

验收脚本：`scripts/check-catalog.cjs` 覆盖新增、校验、编码、规则切换、目录、查询、详情、编辑及响应式弹窗；`scripts/check-ui.cjs` 检查五个页面与图表。脚本使用开发环境已有的 Playwright（可通过 `PLAYWRIGHT_MODULE` 指定模块路径），业务项目无需安装测试依赖。

## 智慧轮巡模块

打开 `/#/smart-patrol`，点击“开始智慧轮巡”：CAM001～CAM003 检测正常，CAM004 在 G4 K2035 发现疑似事故（96%，待复核）。逐路分析与间隔共约 14 秒。点击“高码流复核”后依次申请、切换、复核，每阶段约 2 秒，确认事故（99%）并生成唯一事件记录。自动流程约 20 秒，现场讲解可在待复核处停留。

默认四路均为 640×360 / 512kbps；复核时仅 CAM004 切换为 1920×1080 / 4Mbps。带宽按低码流 0.5Mbps 的演示口径计算，从 2.0Mbps 变为 5.5Mbps；确认后保留高清画面供讲解，重置时释放。参数变化为前端模拟，不会实际调度或提升视频清晰度。

无 MP4 时展示离线道路车辆动画。可将本地 MP4 放入 `public/videos/`，优先匹配 `CAM001.mp4`～`CAM004.mp4`，未匹配时该路继续使用模拟画面，不借用其他点位视频。添加素材后重启开发服务，生产版本需重新构建。视频静音循环播放，加载失败回退动画，不请求外部视频。不同码流可使用同一演示素材。

检测类型默认全部启用，识别结果为固定主线模拟。日志随操作生成。执行中的按钮禁止重复触发，“重置演示”取消所有未完成步骤并清空轮巡事件。分析中离开页面会取消任务；复核中离开会退回低码流待复核；已确认结果跨页面保留，并在同一标签页刷新后恢复；未完成轮巡或复核会安全停止，日志刷新后清空。

`src/data/events.js` 的 `eventScenario` 统一主线参数，`confirmedEvents` 保存确认记录，`confirmedMainEvent` 提供最新主线事件，包含道路、桩号、摄像机、暴雨、18km/h、4200辆/h、2.3km 排队长度等字段。堵点分析优先消费该响应式确认记录，承接本轮事件。首页静态示例不受重置影响。已确认主事件保存为当前标签页会话检查点。

实现文件：`src/views/SmartPatrol.vue`、`src/composables/usePatrol.js`、`src/components/patrol/`、`src/data/patrol.js`、`src/assets/patrol.css`。验收脚本 `scripts/check-patrol.cjs` 覆盖真实时间完整流程、异步阶段重置、路由切换、记录去重、共享数据及响应式布局；沿用上述 Playwright 环境配置。

## 堵点分析模块

打开 `/#/congestion-analysis`。优先读取 `events.js` 的 `confirmedMainEvent`；尚未轮巡确认时，`analysisEvent` 使用同一 `eventScenario` 的预置已确认样例（明确标注来源），不向轮巡事件列表写入假记录。真实演示流程中的事件编号、发现时间及复核置信度直接来自轮巡记录。

七个节点 K2020～K2050 均可点击，K2035 始终为事故主线。其他节点展示各自运行指标；分析对象仍为 K2035。点击“启动堵点分析”，按 0.9 秒一步完成数据接入、融合、异常识别、堵点定位和原因研判，约 4.5 秒后显示严重拥堵结论。支持重新分析、任意阶段重置、查看关联事件；离开页面取消正在执行的定时器，已完成结果跨页保留。

趋势图使用双轴展示速度与流量；诱因条形图仅在完成分析后显示 65% / 25% / 10%，明确标注为演示模拟结果。趋势时段统一为 13:35—14:00，下一阶段推演基准为 14:00；事件发现时间保留原记录，两种时间口径在页面说明。

`traffic.js` 管理道路节点、运行指标、天气、趋势、诱因及 `currentCongestion` 响应式输出。输出包含 `eventId`、`source`、`currentTime`、`road`、`location`、`camera`、`speed`、`flow`、`density`、`queueLength` / `congestionLength`、`eventType`、`weather`、`level`、`mainCause`、`causeFactors` 和 `analyzedAt`。结果只在分析完成后存在，重置分析或替换/重置上游事件后失效，同一标签页刷新可恢复已完成分析。态势推演直接读取该对象；没有结果时提示先完成堵点分析，并禁用推演按钮。

新增组件位于 `src/components/congestion/`，状态逻辑为 `src/composables/useCongestion.js`，专属样式为 `src/assets/congestion.css`。`scripts/check-congestion.cjs` 验证节点、流程、图表、共享输出、轮巡联动、重置取消及屏幕布局，运行方式沿用前述 Playwright 环境。

## 交通态势推演模块

打开 `/#/traffic-simulation`，先完成堵点分析。页面以 `traffic.js` 的 `currentCongestion` 为唯一业务输入，显示原事件编号、摄像机及数据来源；无分析结果时提供返回分析入口，不创建新的事故或伪造分析结果。

点击“开始态势推演”，约 5.4 秒按 1.8 秒间隔播放 14:00 → 14:10 → 14:20 → 14:30。节点状态、拥堵范围示意、指标卡与曲线高亮同步变化。拥堵长度 / 排队长度为 2.3、3.6、5.1、6.8km，速度为 18、15、12、10km/h；未来时点采用预设情景，初始指标读取分析输出。影响走廊是预警范围，不等同于连续拥堵长度；地图不按真实距离绘制。预计持续时间为所选时点起的预置剩余时长，平均扩散速度为相对14:00的长度增量除以经过分钟数。

随时点击时间点会停止自动播放并进入手动查看；完整结论仅在自动播放结束后出现。“重新推演”从14:00重新开始；“重置”不影响上游数据。播放中重复启动被阻止，离开页面会取消定时器；再次进入时若此前已完整推演，则恢复14:30完成结果；中断的任务从初始状态开始。堵点分析结果被重置或替换后，推演立即复位；同一标签页刷新可恢复已完成分析及推演检查点。

“模型设计”用五层结构展示数据输入、融合、状态识别、态势推演和服务输出，同时明确说明实际 DEMO 使用固定情景查表和定时状态切换，不执行真实AI预测或交通仿真。道路通行能力采用“事故影响下受限”的定性模拟输入；建议均标为演示建议。

时间轴和模型说明数据集中在 `src/data/traffic.js`：`simulationTimeline`、`simulationNodes`、`simulationSteps`、`simulationModel`、`simulationAdvice`。组件位于 `src/components/simulation/`，状态逻辑为 `src/composables/useSimulation.js`，样式为 `src/assets/simulation.css`。沿用公共 ECharts 生命周期管理，未增加业务依赖。

`scripts/check-simulation.cjs` 覆盖缺少输入、四时点自动与手动切换、节点颜色、图表高亮、重新推演、六阶段重置、离页取消、上游失效、模型弹窗和完整轮巡→堵点→推演链路。全流程引导已整合；继续保留纯前端、全模拟、离线运行范围。

## 全流程演示与现场使用

首页顶部点击“进入演示模式”，从1/6开始。引导条显示操作建议和讲解时间，通过“上一步 / 下一步”人工切换，不会定时跳页。第3步需发现疑似事故，第4步需完成高码流复核，第5步需使用本轮事件完成堵点分析，才能继续。“退出演示”仅隐藏引导，保留业务结果；“重新演示”清除本轮事故、堵点分析和推演检查点并返回第1步，视频编目样例及本次新增不受影响。

建议10～15分钟安排：总览1～2分钟 → 视频编目2～3分钟 → 轮巡2分钟 → 高清复核1～2分钟 → 堵点分析2～3分钟 → 推演与模型设计2～3分钟。动画耗时分别约20秒、4.5秒、5.4秒；其余时间用于讲解、手动回看与规则说明。

非演示模式也可顺序操作：确认事故后“进入堵点分析” → 分析完成后“进入态势推演” → 推演完成后“返回路网总览”。首页提供四个业务快捷入口。主线编号统一为 `EVT-2026-0001`（固定演示编号，不随电脑年份变化）；摄像机CAM004、G4 K2035及基础指标由 `coreDemoEvent` 统一提供。

刷新恢复范围：`sessionStorage` 保存同一标签页的引导步骤、已确认主事件、已完成堵点分析及完整推演检查点。F5不会丢失这些完成结果，也不会续跑旧定时器。未确认的疑似事件和实时日志不恢复，返回轮巡重新开始即可。视频编目新增/编辑与编码规则仍仅在运行内存保留，刷新恢复初始15条样例。关闭标签页或新建独立会话时需重新演示。存储不可用或数据损坏时回退安全初始状态，不影响页面打开。

每次现场演示前，进入项目目录运行 `npm run dev`，保持终端运行，再访问 http://127.0.0.1:5173/ 。本地服务停止时网址不可访问，这与页面数据恢复是两件事。部署构建版可执行 `npm run build` 后运行 `npm run preview`，不要直接双击HTML文件。

`src/data/demoGuide.js` 管理六步提示，`src/components/DemoGuide.vue` 管理引导交互，`src/data/demoSession.js` 管理检查点，`src/assets/integration.css` 集中定义收口视觉规范。`scripts/check-integration.cjs` 验证六步链路、检查点、重新演示、常规屏幕适配以及五页面普通/演示模式的1920×1080一屏布局。其他专项脚本继续验证业务交互及真实动画节奏。所有验收均可使用外部Playwright运行时，不向业务包新增大型依赖。

# 第七轮：展示效果与最终交付

顶部提供“系统说明”“截图模式”“重置演示数据”。全量重置需要确认，恢复15条基础视频、默认编码规则，清空本轮事件、分析和推演结果，回到演示步骤1/6。引导条的“重新演示”仅重启业务主线，保留视频编目；页面内的重置仅作用于本模块及其下游结果。

截图模式隐藏引导条和辅助按钮，保留页面标题、业务图表与演示模拟数据标识；再次点击退出。先完成业务操作，再开启截图模式。

本地视频配置统一位于 `src/data/cameras.js` 的 `cameraMedia`。支持 `public/videos/cam001.mp4` 至 `cam004.mp4`（文件名大小写兼容），推荐浏览器支持的 H.264 MP4。没有素材也能完整演示；损坏或编码不支持时回退动画。低/高清使用同一素材，清晰度差异是CSS模拟，不代表视频实际分辨率发生变化。

交付文档：[演示操作说明](DEMO_GUIDE.md)、[系统功能说明](SYSTEM_DESCRIPTION.md)、[截图清单](SCREENSHOT_LIST.md)。截图保存至 `report-assets/screenshots/`。
